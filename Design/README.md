# Blindlog Wallet icon

`blindlog-icon-master.png` is the generated source artwork. The pass bundles
29×29, 58×58, and 87×87 PNG exports under `Sources/App/Resources/PassIcon`.
The square icon is used for the pass icon only; the event title remains the logo text.

Generated with the built-in ImageGen tool. Prompt:

> Use case: logo-brand
> Asset type: production Blindlog Apple Wallet event pass icon, square 1024x1024 master PNG.
> Primary request: Create a refined minimal brand icon for Blindlog, a blind wine tasting event app. One bold ivory wine glass silhouette, with a simple wine-colored fill suggesting red wine in its bowl, centered on a solid deep burgundy square background. Strong clean geometry, balanced bowl/stem/base, substantial strokes and simple silhouette that remains crisp and recognizable at 29x29 pixels. Tasteful contemporary flat graphic, no texture or gradients, no shadows or 3D. Large centered symbol occupying about 70 percent of the square, generous even safe margins. Background extends fully to all four square corners; no rounded-square border or framing. No letters, words, numerals, watermarks, additional objects or mockup. Return just the single finished icon.

Export the PNGs using `sips -z SIZE SIZE Design/blindlog-icon-master.png --out DESTINATION`.
